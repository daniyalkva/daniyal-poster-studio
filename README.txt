DANIYAL POSTER STUDIO — STARTER WEBSITE

Files:
- index.html: your poster-order website.

IMPORTANT:
This starter version prepares an email on the customer's device. It does NOT automatically deliver orders to you yet.

To collect poster orders online, create a Google Form at https://forms.google.com with poster type, size, instructions, quantity, budget, required date and contact details. Then embed the form in Google Sites or link the order button to it.

To publish this HTML version with GitHub Pages:
1. Sign in at https://github.com
2. Create a public repository named daniyal-poster-studio
3. Upload index.html to the repository root.
4. Open Settings > Pages.
5. Choose Deploy from a branch, select main and /(root), then Save.
6. Wait for GitHub Pages to provide the public address.

The contact section includes the phone/WhatsApp number you supplied. Publishing makes that number visible to visitors, so only keep it if you are comfortable sharing it.
